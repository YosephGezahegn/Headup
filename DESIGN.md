# Design System: ራስ በራስ (Ras Be Ras)
**Project ID:** 13970646922971875641

## 1. Visual Theme & Atmosphere
The design is vibrant, inviting, and cultural, reflecting the spirit of an Ethiopian party game. It features a high-contrast aesthetic with a clean, modern card-based layout set against an airy, off-white background. The atmosphere is energetic and celebratory, emphasized by bold yellow primary accents and the iconic green-yellow-red of the Ethiopian flag.

## 2. Color Palette & Roles
*   **Ethiopian Gold (#ffcc00):** The primary brand color. Used for large action buttons, the gameplay screen background, and active navigation states.
*   **Canvas Off-White (approx. #FFFDF7):** The main application background. Provides a warm, readable surface for the content.
*   **Pure White (#FFFFFF):** Used for category cards and form input fields to create depth and contrast against the background.
*   **Slate Grey (#333333):** The primary text and icon color for high legibility.
*   **Flag Trio (Green #009B4D, Yellow #FEDD00, Red #EF3340):** A semantic accent used exclusively for the top borders of category cards, grounding the app in its cultural context.
*   **Teal Info (approx. #E0F2F1):** A soft, calming background for instructional information boxes.

## 3. Typography Rules
*   **Font Family:** Plus Jakarta Sans (Primary) and Noto Sans Ethiopic (for Amharic text).
*   **Headers:** Bold, large sizing (24px-28px) in Slate Grey. Amharic script is given visual priority.
*   **Secondary Text:** Medium weight (14px-16px) in slightly muted grey for labels and captions.
*   **Letter Spacing:** Standard, optimized for clear reading of both Latin and Ethiopic characters.

## 4. Component Stylings
*   **Buttons:** Large, "squircle" rounded corners (approx. 12px-16px) with Ethiopian Gold background. Primary actions feature prominent icons and bold centered text.
*   **Cards/Containers:** "Bento-style" grid cards with standard rounded corners (8px-12px). They feature a subtle drop shadow for elevation and a characteristic three-color top border.
*   **Inputs/Forms:** Clean, "ghost-style" or white-filled fields with soft rounded edges and no heavy borders. Interactive "chips" for word lists are used to show added items clearly.
*   **Bottom Navigation:** Minimalist bar with active states highlighted in the primary Ethiopian Gold.

## 5. Layout Principles
*   **Grid System:** A responsive 2nd column grid for the home screen to allow for easy thumb navigation on mobile.
*   **Whitespace:** Generous padding (approx. 20px) around content blocks to maintain a clean and uncluttered interface.
*   **Hierarchy:** Progressive disclosure is used in the creation flow, with clear separation between input sections and informative tips.
